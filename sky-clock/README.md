# 天空窗

为 DSH 换肤制作的本地交互原型。用浏览器打开 `index.html` 即可，不需要安装依赖或启动服务。

- 按城市当地日期、时区和太阳高度，连续生成晨光、晴空、晚霞与夜色。
- 太阳沿日出到日落的半圆时钟移动；半圆表示时间进度，并非真实方位投影。
- 分层云朵缓慢漂移，夜间出现月牙和稀疏星光；支持减少动态效果。
- 点击太阳或「抬头看看」展开天空，点击「回到工作」或按 Esc 返回。
- 角落的天空设置提供城市、可选定位、日期与时间预览、「看一天」、恢复实时、天空浓度和云朵开关。
- 日夜配色覆盖侧栏、消息、代码块、输入框和设置。城市和外观偏好仅保存在本地浏览器。
- 可输入消息，或载入代码与设计示例，检查不同天色下的阅读体验。回复为固定本地示例，尚未连接 DSH / 模型。

天空采用晴天插画，不读取实时天气。太阳计算不需要联网；定位仅在用户点击按钮后请求浏览器授权，当前位置使用设备时区。

## 文件

- `index.html`：工作区、天空插画和设置结构。
- `styles.css`：布局、日夜主题变量、缓慢云层与响应式适配。
- `app.js`：氛围配色、当地时间、时间预览、对话示例与交互。
- `solar.js`：独立太阳计算模块，处理 IANA 时区、夏令时、极昼和极夜。

## 验证

在项目目录运行：

```powershell
node --test .\sky-clock\solar.test.cjs .\sky-clock\app.test.cjs
```

这些检查覆盖太阳和时区计算、界面状态与配色对比度。最终在 DSH 中的视觉表现仍需接入真实客户端后验证。
