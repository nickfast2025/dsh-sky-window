## 0.1.0 — 2026-10-19

- Illustrated sky based on city time, with a daytime sun path, dawn, sunset, moon, and stars. / 按城市当地时间变化的插画天空，包含白天太阳轨迹、晨暮、月亮和星光。
- Immersive sky, time and date preview, day playback, and a paused sky as wallpaper. / 沉浸看天、日期时间预览、播放一天及暂停壁纸。
- Translucent DeepSeek cloud, slow cloud motion, and reduced-motion support. / 半透明 DeepSeek 云朵彩蛋、缓慢漂移及减少动态效果支持。
- Native DSH theme, overlay, and settings integration; home controls hide during conversations. / 接入 DSH 原生主题、浮层与设置，对话时收起首页入口。
- Windows launcher, Chinese and English documentation, screenshots, and video. / Windows 启动脚本、中英说明、截图和视频。

Validation scope and per-version adjustments are recorded in the README compatibility table. / 验证范围与逐版调整记录见 README 兼容表。

Known limits: Windows Web is the tested interface; no live weather or nighttime moon trajectory. DSH version checks are not pinned, and untested versions need their own verification. / 当前实测界面为 Windows Web；不接实时天气、不计算夜间月亮轨迹；不锁定 DSH 版本，未测版本仍需验证。
