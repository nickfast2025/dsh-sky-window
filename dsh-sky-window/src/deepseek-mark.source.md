# DeepSeek whale mark

`deepseek-mark.svg` is an unmodified copy of `dist/favicon.svg` from the locally
installed official `@deepseek-ai/dsh-web-frontend` package, DSH 0.1.1-rc.2.

Upstream: https://github.com/deepseek-ai/deepseek-harness

The background uses the complete original compound path, including every
interior cutout and its original `fill-rule`. The build discards the source's
black fill and media style; scene CSS gives the small floating mark the same
color and translucent appearance as the nearby clouds. It is a quiet sky
easter egg rather than a separate mascot. No PNG image is read or embedded.
