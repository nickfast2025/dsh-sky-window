# DSH 天空窗

[简体中文](./README.md) · [English](./README.en.md)

> 给长时间对着屏幕的人，一扇会流动的天空。

![北京同一天的晨光、晴空、暮光与夜色四宫格](./docs/images/00-day-in-four-scenes.png)

晨光、晴空、暮光、夜色。四张画面来自实际运行的 DSH，同一天、同一城市的时间预览。四宫格保留了每张截图的原始像素，点击图片可查看大图。

天空窗是 DeepSeek Harness 的原生换肤插件。它按照所选城市的当地时间，让太阳沿半圆轨迹移动，并让天空从晨光、晴空、晚霞自然过渡到月色与星空。

大部分时间，天空安静地留在工作内容后面；想短暂离开屏幕里的任务时，可以点一下「抬头看看」。

## 体验

### 工作时，天空留在身后

原生侧栏、会话、输入框和模型设置保持可用。工作首页右下角有时间、城市和进入天空的入口；进入对话后，这组入口会收起，避免遮挡模型与统计信息。长对话后面有一层轻柔的阅读背景。

![工作区中的天空窗](./docs/images/02-workspace-skin.png)

### 抬头时，只看一会儿天

沉浸模式减少了文字与控件：太阳轨迹说明一天走到了哪里，云朵缓慢漂过，底部角落保留返回工作和播放一天的入口。

![天空窗沉浸模式](./docs/images/01-immersive-sky.png)

### 沿着时间看天空

拖动时间轴，或直接选择日出、正午、日落和夜空。顶部的玻璃状态条会随着天空取色，同时保留清晰的「回到此刻」。

### 把喜欢的时刻留作壁纸

在天空页暂停到一个时刻，再回到工作，所选天空会保持不动。工作区不会悬浮预览提示；需要恢复实时天空时，再进入「抬头看看」。

![冻结日落作为工作区壁纸](./docs/images/06-frozen-wallpaper.png)

### 调整一扇属于自己的窗

可以选择城市或在点击后使用浏览器定位，调节天空浓度、暂停云朵动效，也可以让一天自动掠过。

![天空窗设置](./docs/images/03-sky-settings.png)

## 功能

- 根据城市、日期与当地时区估算日出、日落和太阳位置。
- 太阳沿半圆轨迹移动，天空颜色按照太阳高度连续变化。
- 早晚呈现晨光与晚霞，夜间显示月牙和星光。
- 支持时间轴、日期、日出、正午、日落、夜空和一天播放。
- 暂停预览后可把当前天空留作工作区壁纸。
- 天空玻璃控件自动适配白天、晚霞与夜空的色调。
- 云朵缓慢漂移，并响应系统的「减少动态效果」设置。
- 官方 DeepSeek 标志以半透明云朵彩蛋出现，和普通云保持相近的漂移节奏。
- 城市、天空浓度和动效偏好只保存在本机浏览器。

## 在此项目启动

需要 Node.js 22 或更高版本。首次安装 DSH 时，可运行 `npm install --global @deepseek-ai/dsh@0.2.1-rc.2`；已有 DSH 可直接使用现有安装。在完整仓库的根目录运行：

```powershell
.\start-dsh-sky.ps1
```

默认地址为 `http://127.0.0.1:3081`。启动器会读取本机 DSH 版本、构建插件，并使用项目内独立的开发 Profile：`.runtime/dsh-home`。它不限制具体 DSH 版本；已实测的版本见下方。

浏览器未自动打开时，使用终端中 DSH 打印的完整认证链接。若端口被占用，可加 `-Port 3085`；在终端按 Ctrl+C 停止服务。

这是实际的 DSH 服务。首次使用模型时，请在 DSH 原生设置中完成配置。天空窗不会读取或迁移已有的 API Key、模型设置及聊天记录。

这个本地 Windows 启动方式把 DSH 的工作区目录选择器固定为网页浏览模式。点击侧栏「工作区」旁的添加按钮，可浏览目录、创建文件夹并将其作为新工作区打开。此配置仅作用于项目内的开发 Profile。

## 安装到已有 Profile

下载并解压完整仓库后，在仓库根目录打开 PowerShell。先打包，再用 DSH 官方命令安装到自己的 Profile；下面以 `web` 为例：

```powershell
cd .\dsh-sky-window
npm pack
dsh plugin --profile web add .\dsh-sky-window-0.1.0.tgz
dsh web
```

`npm pack` 会自动构建；插件源码使用 Node 内置模块，无需额外安装依赖。`dsh web` 应从你希望作为工作区的目录运行。若该 Profile 已在运行，安装后重启它，再在 DSH 设置中打开「天空窗」。同一 Profile 若启用了其他背景插件，可先关闭其背景层，避免样式覆盖。

安装到已有 DSH 时，继续使用原有启动命令（包括自定义端口参数）、地址和端口。天空窗插件运行在该 DSH 服务中，不会另开一个服务，也不要求使用 `3081`。

只想暂时停用时，在「天空窗」设置里关闭「启用天空窗」，原主题会恢复。完整卸载使用：

```powershell
dsh plugin --profile web remove dsh-sky-window
```

卸载后重启该 Profile。以上插件命令使用你当前的 `DSH_HOME`；项目根目录启动器使用的是自己的 `.runtime/dsh-home`。

## 常见问题

- **网页提示需要认证**：重新打开 DSH 本次启动打印的完整链接。不要把含登录令牌的链接发到 issue。
- **PowerShell 提示脚本被阻止**：下载的 ZIP 可能带有来源标记；确认源码后，可对根目录的启动脚本运行 `Unblock-File .\start-dsh-sky.ps1` 再启动。
- **输入框提示选择工作区**：先点击侧栏「工作区」旁的添加按钮并选择目录；模型还需在 DSH 原生设置中配置。
- **其他换肤覆盖天空或长对话样式异常**：先停用同一 Profile 的其他背景插件；反馈时附 DSH 版本、系统和复现步骤。

## 使用

1. 点击侧栏「工作区」旁的添加按钮，选择已有目录，或先「新建文件夹」再打开。
2. 在工作首页从右下角的「天空窗」打开设置并选择城市。
3. 点击「抬头看看」进入沉浸天空。
4. 使用设置中的时间轴或四个时间预设观察一天的变化。
5. 在喜欢的时刻点击「回到工作」，把它留作当前壁纸。
6. 再次进入天空页，点击「回到此刻」恢复实时流动。

## 实现与边界

- 新安装优先推荐 **DSH 0.2.1-rc.2**。正式 0.1.0 包已在独立安装和 Profile 中通过官方安装、卸载、天空预览与播放、暂停壁纸、恢复实时、偏好保存、停用恢复主题及真实模型对话。已有 **DSH 0.1.1-rc.2** 环境可以继续使用。[七个 RC 版本的逐项记录](../README.md#兼容性)列出了其余版本的运行情况、调整和未测项。
- 插件不声明固定 DSH 版本。DSH 与插件的接口若发生变化，安装成功仍不等于全部功能兼容；以上仅是已观察到的范围。
- 插件通过官方 `ctx.theme` 和 `ctx.slots` 接口叠加主题、背景、入口与设置面板。
- 日夜主题通过 DSH 主题注册和 token 覆盖应用；关闭天空窗后会恢复此前主题。
- 半圆表示日出到日落的当地时间进度，天文时间为本地算法估算。
- 夜间暂不计算月亮轨迹，也不获取实时天气。
- 定位只在用户点击「定位」后请求浏览器授权。
- 对话阅读背景适配已覆盖上述两个实测版本的容器层级；未来布局变化需要重新检查。

## 构建与测试

```powershell
node build.mjs
npm test
npm pack
```

`build.mjs` 会把源码、矢量天空和太阳算法打包进 `lib/client.js`，运行时没有 CDN、图片下载或其他网络依赖。DeepSeek 云朵彩蛋直接使用本地矢量轮廓，由场景颜色和透明度控制。
